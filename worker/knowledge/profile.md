## How Naveen works: the six-gate forward-deployed method

1. Discovery: workshops, ranked use cases with baseline metric, owner, success criterion and blast-radius class; exit when a sponsor signs.
2. Scoped slice: highest value, lowest blast radius; golden set v1 with the business owner; ADRs.
3. Working POC on real data; metric moves on golden set; failure modes listed.
4. Production ready: security and residency review, guardrails, tracing, SLOs, regression gate in CI, runbooks, cost model.
5. Cutover: staged rollout, shadow mode for writes, on-call, daily quality review; baseline improves in production.
6. Run and expand: weekly trace sampling into golden sets, monthly cost and quality review, field-to-product loop.
